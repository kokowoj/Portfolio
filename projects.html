01 · CREATIVE CODING

Star Trail

Star Trail is a mouse-following particle effect made with JavaScript and p5.js. As the cursor moves, colorful stars appear, drift, and gradually fade away. I used the effect to add personality and interactivity to my earlier website, and the same effect is part of this portfolio's design.

Project preview: a short screen recording showing the star-trail particle effect in motion.

Tools: p5.js, JavaScriptFocus: particles, animation, interaction
